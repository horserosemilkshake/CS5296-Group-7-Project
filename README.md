# Project Snapshot

This project is a real-time speech and NLP platform that combines a Python backend, a static JavaScript frontend, Docker Compose, Kubernetes manifests, Nginx routing, Prometheus/Grafana monitoring, and Vosk-based local ASR models into one deployment-heavy stack.

It is the kind of architecture where saying "hello world" requires a small cloud strategy meeting, 30 YAML files, and an emotional support dashboard.

Honestly, the stack would be much simpler if we just use Overlord, Director, and AppJail in FreeBSD. But I guess people just don't appreciate the perfect old solution we already have decades ago.
